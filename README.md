# Carreira_Tech
[![CI](https://github.com/bruno1186/Alura_Trainning/actions/workflows/ci.yml/badge.svg)](https://github.com/bruno1186/Alura_Trainning/actions/workflows/ci.yml)

Repositório de estudos e material de referência cobrindo temas fundamentais para engenharia de software e dados, organizado por trilha. Cada pasta contém um README com conceitos, boas práticas e, quando aplicável, exemplos de código.

## Trilhas

| Trilha | Conteúdo |
|---|---|
| [Arquitetura de Sistemas](./arquitetura-de-sistemas) | Estilos arquiteturais, trade-offs, monolito x microsserviços, event-driven |
| [System Design](./system-design) | Método para resolver problemas de design, escalabilidade, cache, filas, sharding |
| [Engenharia de Software](./engenharia-de-software) | Princípios SOLID, Clean Code, ciclo de vida, versionamento, CI/CD |
| [Engenharia de Dados](./engenharia-de-dados) | Pipelines ETL/ELT, modelagem de dados, qualidade de dados |
| [Ciência de Dados](./ciencia-de-dados) | Fluxo de análise, EDA, estatística aplicada, introdução a ML |
| [Qualidade (BDD/TDD)](./qualidade-bdd-tdd) | Test-Driven Development e Behavior-Driven Development, com exemplos executáveis |

## Como usar

Cada trilha é independente e pode ser estudada na ordem que fizer mais sentido para o seu momento. As trilhas de Engenharia de Dados, Ciência de Dados e Qualidade incluem código de exemplo executável, com testes cobertos por CI (GitHub Actions).


## Materiais Recomendados

Uma seleção de referências externas para quem quer aprofundar os estudos em tecnologia, incluindo instituições de ensino reconhecidas no Brasil e no exterior.

**Alura** — plataforma brasileira de cursos online de programação, dados e carreira em tech ([alura.com.br](https://www.alura.com.br)). Destaque para os repositórios das imersões práticas, como [aluraquiz-base](https://github.com/alura-challenges/aluraquiz-base) e [introducao-a-data-science](https://github.com/alura-cursos/introducao-a-data-science).

**FIAP** — faculdade de tecnologia hoje integrada ao grupo Alura, com cursos de pós-graduação em Machine Learning e Engenharia de Dados. Exemplos: [fiap-ml-visao-computacional](https://github.com/michelpf/fiap-ml-visao-computacional) e [Materiais-MLET](https://github.com/Cataldir/Materiais-MLET).

**POLI (Escola Politécnica da USP)** — referência acadêmica brasileira em engenharia, com repositórios de disciplinas e projetos históricos, como o [PatinhoFeio](https://github.com/ArqueologiaDigital/PatinhoFeio), documentação do primeiro computador brasileiro.

**MIT** — através do MIT OpenCourseWare, disponibiliza gratuitamente materiais de disciplinas de ciência da computação. Exemplos: [MIT6006](https://github.com/avhn/MIT6006) (Introduction to Algorithms) e [awesome-MIT-OCW](https://github.com/m0r4a/awesome-MIT-OCW).

**Stanford** — cursos abertos como o CS229 (Machine Learning) geraram materiais muito populares, como os [cheatsheets de CS229](https://github.com/afshinea/stanford-cs-229-machine-learning) e as [notas completas do curso](https://github.com/maxim5/cs229-2018-autumn).
