# Alura_Trainning

[![CI](https://github.com/bruno1186/Alura_Trainning/actions/workflows/ci.yml/badge.svg)](https://github.com/bruno1186/Alura_Trainning/actions/workflows/ci.yml)

Repositório de estudos e material de referência cobrindo temas fundamentais para engenharia de software e dados, organizado por trilha. Cada pasta contém um README com conceitos, boas práticas e, quando aplicável, exemplos de código.

## Trilhas

| Trilha | Conteúdo |
|---|---|
| [Arquitetura de Sistemas](./arquitetura-de-sistemas) | Estilos arquiteturais, trade-offs, monolito x microsserviços, event-driven |
| [System Design](./system-design) | Método para resolver problemas de design, escalabilidade, cache, filas, sharding |
| [Engenharia de Software](./engenharia-de-software) | Princípios SOLID, Clean Code, ciclo de vida, versionamento, CI/CD |
| [Engenharia de Dados](./engenharia-de-dados) | Pipelines ETL/ELT, modelagem de dados, qualidade de dados |
| [Ciência de Dados](./ciencia-de-dados) | Fluxo de análise, EDA, estatística aplicada, introdução a ML |
| [Qualidade (BDD/TDD)](./qualidade-bdd-tdd) | Test-Driven Development e Behavior-Driven Development, com exemplos executáveis |

## Como usar

Cada trilha é independente e pode ser estudada na ordem que fizer mais sentido para o seu momento. As trilhas de Engenharia de Dados, Ciência de Dados e Qualidade incluem código de exemplo executável, com testes cobertos por CI (GitHub Actions).
